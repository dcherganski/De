Vision

AI that knows the person, not just the prompt.

The problem

Most AI assistants start every conversation almost from zero. Context is scattered across apps and devices, and people repeat themselves again and again. When an assistant does remember, it is often unclear what it keeps and how to make it forget.

The KATE idea

A single, natural conversation that builds a long-term understanding of each person — their preferences, projects and way of working — with a memory that belongs to them, can be inspected, and can be deleted for good.

  • Personal. Each user has a separate memory. Nothing is shared between people.
  • Continuous. One assistant across the devices you already own.
  • Accountable. Clear about what it remembers and why.

Privacy & Memory

Your memory. Your decision.

Planned product rule

If you delete your personal memory in KATE, the linked profile is deleted permanently as well.

Deleting memory is not a hidden setting. It is one deliberate action that removes what KATE knows about you together with the profile it belongs to.

  1. 1

    Clear warning

    KATE explains exactly what will be removed and that it cannot be undone.

  2. 2

    Explicit confirmation

    You confirm on purpose — no accidental taps.

  3. 3

    Memory and profile removed

    The memory and the linked profile are deleted together.

This describes the intended design. Before KATE stores any personal data or opens registrations, the policy will go through legal and technical review, and it will respect users' statutory rights, including those under the EU General Data Protection Regulation (GDPR).
